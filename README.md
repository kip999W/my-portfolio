# 💼 Портфолио — Frontend-разработчик

Одностраничный (SPA) сайт-портфолио: адаптивная верстка, тёмная тема, интерактивные секции и форма обратной связи с валидацией.

**Стек:** HTML5 · CSS3 · JavaScript (ES6+) · Swiper.js

🔗 **Демо:** https://kip999W.github.io/my-portfolio

---

## 📌 1. Общая информация

| Параметр | Описание |
|---|---|
| **Тип проекта** | Landing / портфолио (single page) |
| **Цель** | Презентация навыков, проектов и контактов разработчика; получение откликов через форму связи |

## 🧩 3. Функциональные требования

### 3.1 Шапка и навигация (`header`)
- Фиксирована сверху (`position: fixed`), backdrop-blur, тонкая нижняя граница.
- Логотип `KIP.` → ссылка на `#home`.
- Меню: `About` (`#about`), `Projects` (`#projects`), `Contact` (`#contact`).
- Кнопка **«Hire me»** → скролл к форме контактов.
- Индикатор прокрутки страницы (scroll progress bar) под шапкой.
- Активный пункт меню подсвечивается при скролле (IntersectionObserver).
- Плавный скролл к якорям (`scroll-behavior: smooth`, offset учитывается).

### 3.2 Hero-секция (`#home`)
- Крупный заголовок с акцентной фразой («builds elegant web experiences»).
- Подзаголовок с описанием стека.
- CTA-кнопки: **«View Projects»** (первичная) и **«Get in Touch»** (ghost).
- Живая статистика: *Projects Completed*, *Years Experience*.
- **Swiper-слайдер технологий**: бесконечная лента (loop), автопрокрутка (autoplay), карточки с названиями и иконками (HTML, CSS, JS, React, Vue, Node.js, TypeScript…).
- Декоративные blur-«орбы» на градиентах фона.

### 3.3 Секция «Обо мне» (`#about`)
- Двухколоночная композиция: фото/визуал + текст.
- Список навыков (skill list) и краткая биография.
- Анимация появления при скролле (reveal-on-scroll).

### 3.4 Секция «Проекты» (`#projects`)
- Сетка карточек (grid, адаптивные колонки).
- Карточки рендерятся динамически из массива `PROJECTS` в `script.js`:
  - название, описание, теги технологий, ссылки (demo / GitHub);
  - hover-эффекты (подъём карточки, акцентная рамка).
- Ограничение отображаемых карточек: до **6** элементов.

### 3.5 Секция «Контакты» (`#contact`)
- Форма: `Name`, `Email`, `Message` + кнопка отправки.
- Вспомогательные блоки: email, соцсети (GitHub / LinkedIn / Telegram).
- Успешная отправка имитируется на клиенте (демо-режим): показ сообщения об успехе и очистка формы.

### 3.6 Подвал (`footer`)
- Копирайт, повтор ссылок на соцсети, кнопка «наверх».

## ✅ 4. Требования к валидации формы

Реализовано в `script.js` (регулярные выражения соответствуют ТЗ):

| Поле | Правило | Сообщение об ошибке |
|---|---|---|
| **Name** | только буквы и пробелы, длина **2–50** символов (`/^[A-Za-zа-яА-ЯёЁ\s]{2,50}$/`) | «Имя должно содержать только буквы, 2–50 символов» |
| **Email** | корректный e-mail (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`) | «Введите корректный e-mail» |
| **Message** | длина **10–500** символов | «Сообщение должно быть не короче 10 символов» |

- Валидация при отправке + сброс ошибки при вводе.
- Некорректные поля помечаются классом `.error`, текст ошибки выводится под полем (`aria-live`).
- Отправка формы перехватывается (`preventDefault`), сервер не требуется (демо).

## 🎨 5. Дизайн-система

### 5.1 Цвета (CSS Custom Properties)
Токены объявлены в `styles.css` и переключаются темой `[data-theme="light"]`:

```css
:root {
  --bg: #0b0f1a;            /* фон страницы */
  --surface: #111827;       /* поверхности карточек */
  --text: #e5e7eb;          /* основной текст */
  --muted: #94a3b8;         /* вторичный текст */
  --accent: #6366f1;        /* акцент (индиго) */
  --accent-2: #22d3ee;      /* второй акцент (циан) */
}
```

### 5.2 Типографика
- **Заголовки:** `Space Grotesk` (Google Fonts, fallback: system-ui, sans-serif)
- **Основной текст:** `Inter` (fallback: system-ui, sans-serif)
- **Мono-акценты (технологии, лейблы):** `JetBrains Mono`

### 5.3 UI-принципы
- Тёмная тема как основная, светлая — через атрибут `data-theme`.
- Скругления 14–24px, мягкие тени, glass-эффекты (backdrop-filter).
- Единые transition-параметры для hover/focus-состояний.
- Фокус-стили для клавиатурной навигации (`:focus-visible`).

## 📱 6. Адаптивность

| Breakpoint | Диапазон | Поведение |
|---|---|---|
| Desktop | ≥ 1024px | Полная сетка, 2–3 колонки проектов |
| Tablet | 768–1023px | Перестройка сеток в 1–2 колонки |
| Mobile | < 768px | Одна колонка, компактная шапка, упрощённый hero |

- Fluid-типографика через `clamp()`.
- Изображения `max-width: 100%`.
- Мобильное меню-бургер (чекбокс + CSS) на малых экранах.

## ♿ 7. Доступность и качество кода

- Семантические теги: `header`, `nav`, `main`, `section`, `footer`, `form`, `label`.
- Aтрибуты `alt` у изображений, `aria-label` у декоративных элементов.
- Сообщения валидации — `aria-live` зоны.
- `prefers-reduced-motion: reduce` — анимации отключаются.
- Корректный contrast ratio текста на фоне тёмной/светлой темы.
